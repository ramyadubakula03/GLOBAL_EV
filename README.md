# 🌍 GLOBAL EV Sales Analysis (2010–2024)

## 📌 Project Overview

The **GLOBAL EV Sales Analysis (2010–2024)** project focuses on analyzing global electric vehicle (EV) market trends over a 15-year period.

The project aims to understand the growth of electric vehicle adoption across different regions, categories, powertrains, and transportation modes.

Using data analysis and interactive Power BI dashboards, this project provides insights into EV market growth, regional performance, powertrain adoption, and emerging trends.

## 🎯 Business Problem

Electric vehicle manufacturers and charging infrastructure companies need to identify high-growth markets, understand customer adoption patterns, and make strategic expansion decisions.

However, analyzing EV sales, stock, powertrain adoption, and regional trends across multiple years can be challenging.

**Objective:** Develop an interactive dashboard to analyze global EV trends and support data-driven business decisions.

## 📂 Dataset Information

The dataset covers global electric vehicle information from **2010 to 2024**.

### Dataset Columns

| Column | Description |
|---|---|
| region | Geographical region |
| category | EV data category |
| parameter | Measurement parameter |
| mode | Transportation mode |
| powertrain | EV powertrain type |
| year | Year of observation |
| unit | Measurement unit |
| value | Recorded measurement |

## 🧹 Data Cleaning & Transformation

The following data preparation activities were considered:

- Identifying and handling missing values.
- Checking and removing duplicate records where appropriate.
- Correcting data types.
- Checking inconsistent categorical values.
- Validating numerical values.
- Preparing data for analysis and visualization.

## 📊 Dashboard Pages

The Power BI report consists of four analytical sections.

### 1. Global EV Market Overview
- Analyze EV market trends across regions.
- Compare different EV categories.
- Identify leading regions.
- Understand overall market growth.

### 2. Powertrain & Mode Insights
- Analyze BEV and PHEV adoption.
- Compare different powertrain types.
- Understand EV distribution across transportation modes.
- Identify powertrain adoption patterns.

### 3. EV Parameter & Unit Analysis
- Analyze different EV measurement parameters.
- Compare values across measurement units.
- Explore regional and category-level differences.
- Understand parameter-specific trends.

### 4. EV Time Series & Comparative Analysis
- Analyze EV trends from 2010 to 2024.
- Compare historical and recent performance.
- Identify peak growth years.
- Study changes in EV adoption over time.
